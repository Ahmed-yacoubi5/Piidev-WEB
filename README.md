# Efficiency and me 
This project is a Web application developed with the symfony framework as part of an academic project "PIDEV" at ESPRIT school of engineering . This app automates most HR procedures , making it easier and more efficient 

## Features

This app offers several features

-manage employees and grant them privileges based on their role and position within the company

-Manage the profiles (CVs, credentials, etc...) of all employeess within the company and keep records of past employees and candidates 

-Add recruitements offers and manage (accept , reject, delay) The Job applications that come with the territory

-Organise all types of events (internships, office celebrations, training programs....)

-Keeo records on absences and vacations , as well as keep the employee well-being in check

## Getting started

in order to view this web app , there are a few requirements: 

-php version : 8.0.3 and above

-symfony version : 6 and above

-IDE : any IDE is acceptable

you also need WAMP server or XAMPP server and the databases used in our project set up on phpMyAdmin

copy the project files from the MAIN branch and launch symfony server from within the IDE terminal
